# Alcheme Public Baseline Licensing

This public baseline is an Apache-2.0 protocol and integration snapshot unless
a file states otherwise. The public export uses the Apache-2.0 text as the root
`LICENSE` file.

This document does not grant rights to the Alcheme name, logos, domains,
official deployments, governance authorities, program IDs, validator/node
identities, or other brand and network identifiers.

## Apache-2.0 Components

The following baseline components are licensed under Apache-2.0 unless a file
states otherwise:

- `programs/`
- `shared/`
- `cpi-interfaces/`
- `sdk/`
- `packages/game-chat-react/`
- `examples/`
- `extensions/contribution-engine/program/`
- `extensions/contribution-engine/extension.manifest.json`
- `docs/schemas/`
- public integration docs and public quickstarts
- protocol, SDK, manifest, and package compatibility tests

Full text: `LICENSE` and `licenses/APACHE-2.0.txt`.

## Not Included In This Baseline

The private development tree contains additional managed runtime and product
surfaces that are intentionally not part of this public baseline, including:

- `services/query-api/`
- `frontend/`
- `mobile-shell/`
- `extensions/anchor-signer/`
- `extensions/contribution-engine/tracker/`
- internal prompts, evals, anti-abuse policy, rate-limit strategy, runbooks,
  deployment scripts, and production signing topology

Those private surfaces may use different licensing or may remain unpublished.

## Trademark And Official Network Boundary

Forks must not use the Alcheme name, logo, domains, official deployment
addresses, official program IDs, official governance authorities, or official
node identities in a way that implies endorsement, affiliation, or continuity
with the original Alcheme project. Forks should use a distinct name and make
their independent status clear.
