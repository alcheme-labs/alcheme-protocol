Alcheme Public Architecture Map

This public map shows the protocol and integration baseline. It keeps the first-party managed runtime visible as a boundary, but not as an implementation that ships in the public repository.

Architecture overview Export policy Programs SDK Integration quickstart
Open protocol Apache-2.0 code and contracts intended for public review.
SDK and integrations Public client surface for external apps and product clients.
Runtime boundary Endpoint contracts are visible; first-party implementation is private.
Private layer Product, operations, prompts, signing topology, and abuse defenses.
Why the private runtime is still shown External developers need to know that runtime endpoints exist. They do not need the first-party implementation to audit the public protocol, SDK, schemas, or extension contracts.
Why this is separate from the internal architecture map The internal HTML maps describe the full development tree. This public map is maintained separately so public exports do not become a misleading source of truth for private development.
