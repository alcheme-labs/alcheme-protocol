Alcheme Public Subproject Map

This public overlay replaces the internal full-tree subproject map in public exports. It keeps README links stable while pointing readers to the public protocol, SDK, schema, extension, and integration surfaces.

For the visual system map, open docs/public-architecture-map.html.

programs

Public Anchor programs for protocol accounts, instructions, authorities, and events.

shared

Shared protocol types and utilities used by public program crates.

cpi-interfaces

CPI helper interfaces and permission contracts for external program integration.

sdk

TypeScript SDK for public program clients, runtime contracts, and server-side helpers.

game-chat-react

Optional React UI components for Alcheme-compatible chat and voice integrations.

game-chat-headless

Headless example showing how an external app can wire SDK runtime clients.

contribution-engine

Public extension manifest and contribution-engine program surface.

contribution-engine-program

Anchor program for contribution ledgers, references, and reputation settlement signals.

identity-registry

Identity and reputation account surface.

event-emitter

Typed event emission surface used by public protocol programs.

access-controller

Permission and relationship checks for protocol actions.

content-manager

Content publication and lifecycle instruction surface.

registry-factory

Registry and extension discovery program surface.

messaging-manager

Public on-chain messaging program surface.

circle-manager

Circle, membership, fork, and knowledge-binding program surface.

external-app-registry

External app identity and registration program surface.

external-app-economics

Bounded external-app economics and review-flow program surface.
